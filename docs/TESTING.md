## 自动检查

运行 npm run typecheck、npm test 和 npm run build。测试覆盖文档分片预算、模型配置、取消、流式输出、改写校验、SQLite 兼容及向量绑定等逻辑。测试使用合成数据，不应导入实际用户数据库。

下载功能测试为 tests/ollamaDownload.test.ts 和 tests/ollamaDownloadHandlers.test.ts，使用模拟响应。scripts/model-download-smoke.cjs 会启动真实 Electron 窗口及独立配置，连接回环模拟服务，验证按钮、进度、取消、切页恢复和模型列表刷新，不下载模型权重。

部分上游测试保留跳过标记，不应将跳过项计作通过。JSON 报告应逐条统计 assertionResults.status，而不是只依赖顶层汇总数字。

## Word 与安装包

Word 验证使用虚构 DOCX，检查解析、预览、建议、应用、导出，以及页眉、页脚、脚注、公式等部件保留。复杂排版仍需在 Microsoft Word 中人工核对。

Windows 打包沿用 electron-builder，包内容检查排除数据库、日志、环境文件、Ollama 程序和模型权重。基本运行验证使用独立测试数据目录，不读取维护者的真实配置。

## 已知边界

- Ollama 必须另行安装和运行，真实模型能力受模型标签、版本及硬件影响。
- 聊天模型不一定支持 Embedding；没有真实可用的向量模型时，不能声称真实 RAG 已验证。
- 下载功能的模拟测试不等于完成所有模型的大文件联网下载。
- 工作区移除记录后，已有历史可能在后续启动回填该文档。
- 当前是 Windows 桌面版，局域网网页与 HTTP 工作站尚未实现。
- 安装程序未签名，预览不保证与 Word 的全部排版行为完全一致。
