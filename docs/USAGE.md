# 桌面版使用手册

## 首次使用

从本仓库 Releases 下载 Windows x64 安装包，运行安装向导。程序不包含 Ollama 或模型；安装后保存自己的模型配置，不会继承仓库中的任何密钥或个人数据。

本地模型使用本机 Ollama，默认地址为 http://127.0.0.1:11434。在功能设置中检测服务，下载模型并保存 Ollama 配置。云端模型则填写服务商地址、自己的 Key 和准确模型名称。不要把聊天模型的名称用于 Embedding，除非该模型明确支持向量接口。

## 文档流程

1. 进入文档校对页，在左侧选择执行模型。
2. 通过“选择文件”导入 DOCX，等待预览完成。
3. 在右上方选择校对、润色或降 AI 等模式并开始处理。
4. 查看进度，必要时取消。失败分片的原文会保留，提示信息会说明失败原因。
5. 检查每条建议，决定是否应用、编辑或忽略。专业术语、事实、数值和限制条件需要人工核对。
6. 点击“导出结果”保存新 DOCX，并用 Word 核对内容和排版。

侧栏工作区按文件夹分组，点击文档可以打开文件并恢复最近校对结果。工作区的“移除”只删除列表记录，源文件保留；存在历史记录时，后续启动的历史回填可能再次收录该文件。移动或删除源文件后，程序会提示文件不存在。

## 模型下载与参数

“功能设置 → API 设置 → 本地模型检测 → 下载模型”提供常见模型及手动名称输入。只有点击下载才联网获取模型。已安装的同名模型会提示检查更新。下载完成后仍需保存模型配置，不会直接替你切换文档执行模型。

进度是当前文件层的进度。取消后可重试，缓存由 Ollama 管理。关闭下载弹窗或切换页面后下载继续，退出程序会中止本程序的请求。下载文件保存在 Ollama 管理的位置。

运行参数位于“本地模型运行参数”。输入、系统提示和输出共享上下文窗口；增大输出预留会减少输入预算。模型文件大小、上下文长度和运行内存是不同概念，设置过大可能导致速度下降或内存不足。先用较短示例文档验证，再处理完整文档。

## 知识库

先保存 Embedding 模型配置，再在本地知识库中创建库并导入材料。文档页选择知识库后，校对流程可使用检索结果。更换模型时，程序会检查模型绑定和向量维度；旧库不兼容时新建知识库重新导入。

真实聊天模型生成能力不等于真实 Embedding 能力。没有可用向量模型时，普通文档处理仍可使用，RAG 则需要先完成配置。

## 备份与常见问题

在“关于应用 → 数据与隐私”查看实际数据目录。退出程序后备份整个目录，包含业务数据库、知识库和会话配置。密钥加密与系统账户有关，复制数据库到另一台机器后可能需要重新填写密钥。

| 提示 | 处理方式 |
| --- | --- |
| 无法连接 Ollama | 确认 Ollama 已启动、地址正确并能检测到模型 |
| 模型不存在 | 核对完整名称和标签，先下载再保存配置 |
| 上下文预算不足 | 核对实际上下文与输出上限，减少额外提示或调整预算 |
| 输出达到上限 | 减少单次内容或调整输出上限，不采用被截断的结果 |
| 部分分片未完成 | 查看具体原因，核对剩余原文；不要将部分完成当作全文完成 |
| 预览与 Word 不完全一致 | 浏览器预览有排版限制，最终以导出文件在 Word 中的检查为准 |

接口错误反馈只提供脱敏状态、模型名称和必要的重现步骤，不上传真实 Key、数据库或完整文档。
