# 隐私与凭据

本项目是个人 Windows 桌面工具。运行时数据库和配置保存在用户应用数据目录，不属于源码的一部分。

## 模型与网络

Ollama 配置限制为回环地址。本地任务不会自动回退云端，辅助审核和 Embedding 也遵循本地任务的网络策略。云端任务则会发送所需文本给用户选择的服务商，使用前应确认配置与文档内容适合该服务。

模型下载通过本机 Ollama 调用官方模型库，仅在用户点击下载时进行。请求不携带文档、提示词或云端 API Key。

## 密钥存储

模型配置存入 SQLite；系统支持时使用 Electron safeStorage 加密 Key。系统加密不可用或加密失败时，现有实现会退回明文并输出告警，因此用户数据目录应按敏感数据保护。加密数据跨系统或账户迁移时可能无法解密，需要重新配置。

日志约定只记录任务摘要、数量、耗时和错误原因，不记录全文或完整 Key。反馈问题时仍须检查并脱敏日志；第三方接口的错误响应也可能带有额外信息。

## 公开仓库

仓库和 Release 不包含维护者自己的模型配置、数据库、文档、登录状态或模型权重。界面截图来自独立测试配置和虚构文档；检测对比图是维护者授权提供的样本分数记录。

发现疑似泄露时，不要将完整密钥粘贴进公开 Issue。先通过对应服务商停用或轮换密钥，再处理仓库中的引用及历史记录。仅删除当前文件并不能使已有历史中的凭据消失。
